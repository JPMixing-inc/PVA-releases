# PVA — PDA Review: downloads

Built releases of PVA, a desktop review workbench for PDI Pile Driving Analyzer submittals.
This repository holds release downloads only.

**Download:** open [Releases](../../releases/latest) and pick the file for your computer:

- macOS: `PVA-<version>-mac.dmg`: open it and drag PVA into Applications. The first time, right-click PVA and choose Open.
- Windows: `PVA-<version>-win.zip`: unzip and run `PVA\PVA.exe`.

Installed copies update themselves: **Help → Check for Updates**.
Each release includes `SHA256SUMS.txt`, and the app checks every download against it before installing.
